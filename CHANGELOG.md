## [1.0.0] - 2026-02-27

### Added
- Real-time crowd detection using Transformers.js (Hugging Face) running entirely in-browser via WebAssembly
- Live camera feed support with configurable detection interval
- Image and video upload for offline crowd analysis
- Density heatmap visualization with color-coded risk indicators
- Dynamic zone segmentation using k-means clustering
- Predictive analytics for crowd congestion (5–7 minute advance warnings)
- Prescriptive capacity recommendations based on venue dimensions
- Missing person search via facial recognition
- Analytics dashboard with weekly and hourly crowd trend charts
- Historical analysis log with export and clear capabilities
- Privacy-first architecture: 100% client-side processing, no data transmitted externally
- Dark/light theme support
- Responsive UI built with React 18, TypeScript 5.8, Vite 5.4, Tailwind CSS, and shadcn/ui
